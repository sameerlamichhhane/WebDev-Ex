Content

HTML documents use elements to give content structure. Headings, paragraphs, lists, images and links each communicate a different purpose.

Good structure helps people scan a page and helps browsers, search engines and assistive technology understand it.

Relative links point to files based on the location of the current document. For example, the link back to the index uses the filename index.html.

Anchor links are useful when a document is long enough that scrolling back to the beginning would be inconvenient.
